暂无

绝大多数安卓手机开 USB 调试都是同一条路，只有「版本号」的位置因品牌而异。 下面按步骤来，找到你手机品牌对应的那一行即可。

第 1 步：打开开发者选项

进入「设置 → 关于手机」，连续点击版本号 7 次，直到提示「您已处于开发者模式」。

版本号在各家系统里的位置（设置 → 关于手机 之下）：

  • 小米 / Redmi：全部参数与信息 → MIUI 版本（澎湃 OS 为「OS 版本」）
  • 华为 / 荣耀：关于手机 → 版本号
  • OPPO / 一加 / realme：关于设备 → 版本号
  • vivo / iQOO：关于手机 → 软件版本号
  • 三星：关于手机 → 软件信息 → 版本号
  • Pixel / 原生安卓：关于手机 → 版本号
  • 魅族：关于手机 → 版本号
  • 中兴 / 努比亚：关于手机 → 版本号

第 2 步：打开 USB 调试

回到「设置 → 系统 → 开发者选项」（部分机型在「设置 → 更多设置」里）， 找到 USB 调试，打开它。

Android 8 及更早版本在「设置 → 开发者选项」；Android 9 及以上在「系统」里面。

第 3 步：连接电脑并授权

用数据线连接电脑，手机会弹出「允许 USB 调试吗」，勾选「一律允许」后点确定。 如果没弹窗，拔插一次数据线，或换一根能传数据的线（充电线常常不行）。

常见问题

  • 找不到开发者选项：版本号没点够，再多点几次；个别定制系统要先登录账号。
  • 连上了但显示「未授权」：在手机上重新确认授权，或到开发者选项里点「撤销 USB 调试授权」再插一次。
  • 小米 / 红米插线只充电：下拉通知栏，把 USB 用途从「仅充电」改成「传输文件」。
  • 华为 / 荣耀：需要在开发者选项里同时打开「仅充电模式下允许 ADB 调试」。
  • vivo / OPPO：部分机型要求先登录厂商账号才能开启。
  • 公司或学校发的手机：可能被管理策略禁用，无法自行开启。

以上步骤来自 Android 官方文档（配置设备上的开发者选项）， 品牌差异部分按各家系统整理。
